# Discord Channel Map Bot

Discordサーバー内のチャンネル構成を自動で整理し、参加者が目的の場所を見つけやすい「チャンネルマップ」を生成・更新するBotです。

## 目的

チャンネルの追加・削除・移動が多いサーバーでは、案内用メッセージを手作業で更新すると、実際の構成とのずれや更新漏れが発生します。

このBotは、現在のカテゴリとチャンネルをDiscordから取得し、常に最新の構成を反映したチャンネルマップを自動で提供することで、次の課題を解決します。

- 初参加者が各チャンネルの役割を把握しにくい
- チャンネル変更のたびに案内を手作業で修正する必要がある
- 古い案内が残り、サーバー内で迷いやすくなる

## 目指すゴール

- サーバー内のカテゴリ・チャンネル構成を自動取得できる
- 指定した案内チャンネルに、見やすいチャンネルマップを投稿できる
- 構成変更を検知し、既存のマップを自動更新できる
- Botの再起動後も、同じ案内メッセージを継続して更新できる
- 管理者が少ない手間で導入・運用できる

最終的には、管理者がチャンネルマップを意識して保守しなくても、参加者がいつでも最新のサーバー構成を確認できる状態を目指します。

## 想定する動作

1. Botがサーバー内のカテゴリとチャンネルを取得する
2. 取得した構成からチャンネルマップを生成する
3. 指定されたチャンネルの案内メッセージを投稿または更新する
4. チャンネルの追加・削除・名称変更・移動を検知した場合、マップを再生成する

## 運用方針

Botは、PCが停止している間も更新を受け取れるよう、Northflankへの常時デプロイを想定しています。

料金プランは事前に無料枠へ最適化しすぎず、まず実際にデプロイしてCPU・メモリ・通信量などを確認します。常時起動する一方で処理が活発になる時間は限定的と見込み、実測結果をもとに無料枠で継続可能か判断します。
