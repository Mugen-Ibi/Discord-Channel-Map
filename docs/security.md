# セキュリティと公開範囲

- Botトークンはパスワード相当です。ローカルは `.env`、NorthflankはRuntime Variables/Secretsに保存し、Gitへ追加しません。`.gitignore` と `.dockerignore` は `.env` 系を除外します。`.env.example` には実値を記入しません。
- トークンが漏れた場合はDeveloper Portalで即時再発行し、実行環境を更新します。Git履歴から消すだけでは無効化されません。
- Administratorを付与しないでください。必要な閲覧・投稿・履歴参照だけを許可します。Botは自分自身のメッセージだけを編集し、ユーザーの投稿や他Botの投稿を変更しません。
- マップ掲載対象はBotと @everyone の双方が閲覧できるカテゴリ・チャンネルです。特定ロール・メンバーへの拒否まで全閲覧者に対して検証する機能ではありません。マップにはチャンネルIDのリンクと公開カテゴリ名が含まれます。公開範囲は実際の運用者が確認してください。
- `allowedMentions: { parse: [] }` で意図しない通知を抑止し、カテゴリ名のMarkdownをエスケープします。
- 同期は即時・トランザクションではありません。非公開化直後やAPI障害、文字数超過中は旧カテゴリ名が残り得ます。機密性の高い名前を公開カテゴリに使わず、緊急時はマップを削除してください。
- エラーは操作の文脈とDiscordの数値コードだけを記録し、トークン・HTTPリクエスト本体・チャンネル構造をログへ出しません。
- `package-lock.json` を管理し、導入・CI・デプロイは `npm ci` を使用します。依存更新時は型チェック・テスト・ビルドとDiscord実環境での確認を行ってください。
- Webhook、Slash Command、受信用HTTPエンドポイント、メッセージ本文収集、DB保存は実装していません。
